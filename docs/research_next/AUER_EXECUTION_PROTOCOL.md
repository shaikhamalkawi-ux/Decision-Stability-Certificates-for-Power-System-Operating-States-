## Actual TSAM algorithm and transparent execution control

Read primary package source `timeseriesaggregation.py` constructor, `_normalizeTimeSeries`, `_preProcessTimeSeries`, `unstackToPeriods`, `createTypicalPeriods`; `periodAggregation.py` k-medoids branch; `representations.py` medoid routine; and `utils/k_medoids_exact.py` in full.

The author helper sorts hourly rows and passes four aggregated signal columns. TSAM sorts columns, applies scikit-learn MinMaxScaler per feature over the168hours, uses `sameMean=False` and empty weights, and flattens each contiguous24-hour day feature-first/time-step-second into96coordinates. Seven days require no padding. Default `evalSumPeriods=False`, `sortValues=False`, segmentation off and no extreme-period insertion apply. The author explicitly selects k-medoids and disables cluster-period rescaling.

Euclidean distances between the seven normalized daily vectors feed TSAM's actual Pyomo49-binary assignment model. Each day is assigned once, exactly three diagonal facilities are selected, and each assignment is bounded by its facility diagonal:57constraints including self inequalities. The returned assignment is processed by TSAM; `medoidRepresentation` recomputes the medoid within each cluster via Euclidean-distance sums and first `argmin`. The harness preserves this tie behavior rather than replacing it with the facility IDs from the optimization.

Source inspection found the TSAM helper's nominal `timelimit`/`threads` attributes are **not forwarded** to its Pyomo solver call. Therefore this harness transparently wraps only `opt.SolverFactory("gurobi").solve` and sets Gurobi `TimeLimit=30`, `Threads=1`, `Seed=0`, `MIPGap=0.0`. It does not change the model, feature processing, returned assignments, medoid recomputation, or author representative-table copying. This is an explicit execution-control variant. Numerical optimal status and a valid rounded binary assignment are required; no exact combinatorial optimality certificate is claimed. A different optimal tie could produce different observations, so each original is repeated and inconsistent repeats make that week's comparisons UNKNOWN. No tie policy is adapted after seeing outputs.

The proxy records actual distance coefficients,49-variable/57-row shape, solver options, returned termination, assignment and objective, and counts the call immediately before it starts. Nonoptimal status, exception, failed shape/finite checks, or failed author output checks yield UNKNOWN, not feasibility or indistinguishability. No fallback. Global patches only capture the actual TSAM instance and intercept its solver factory; both are restored in a `finally` block. Author and package source files remain unchanged.

`--run-prepared` starts a900-second soft phase clock at entry, including validation/imports/I/O, validates all hashes before importing scientific packages, and writes an exclusive execution marker. Each invocation can start its sole Gurobi30-second call only when at least35seconds remain; the guard is rechecked after solver-input serialization immediately before `.solve`. There is no claim that a solver time limit forcibly stops wall time: actual call duration, overrun beyond30seconds, total phase time and any phase overrun are recorded. There is no hidden second solve, recovery solve, adaptive medoid enumeration or extra scientific repeat.

Each invocation stores features, actual multiplicities, normalized daily profiles, solver input/results, selected medoid IDs and Hindex provenance, the complete canonical observation and call ledger. Final outputs retain all failures and compare six targets, three controls and three repeats. Every frozen source/input dependency is rehashed at close. All original research8h files remain unchanged.
