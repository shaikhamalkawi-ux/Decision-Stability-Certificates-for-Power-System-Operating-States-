## Scientific decision and next discriminating questions

The evidence supports an auditable, scoped stress-test result; it does not yet establish publishable methodological novelty. The shared-commitment question is next: can another single exact binary commitment serve both raw week1 chronologies with independent dispatch? A positive answer would refute the stronger no-common-commitment interpretation while preserving the old anchor rejection. The unique week1 joint collision is a disclosed post-hoc target for that new test, not a replacement for the full fifteen-target denominator.

A separate no-optimizer preflight examines whether the official Julia model can be exported and compared to the source-derived OR-LIB encoding. A primary-source review tests potential novelty against established objective-error bounds, feasibility time steps and aggregation refinement. These are concrete unresolved steps, not reasons to call the current paper revolutionary. New work has separate protocols and must not alter these closed results.
