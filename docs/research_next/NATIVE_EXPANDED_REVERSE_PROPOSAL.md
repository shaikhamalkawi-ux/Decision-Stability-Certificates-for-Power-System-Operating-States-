`beta = sum(d_i*l_i for d_i>0) + sum(d_i*u_i for d_i<0)`

`r = c - A^T d`

`L_nom = beta + sum(r_j*a_j for r_j>=0) + sum(r_j*b_j for r_j<0)`

`L_adapter(tau) = L_nom - tau*(sum|d_i| + sum|r_j|)`.
